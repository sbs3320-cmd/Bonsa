# 본사 (2단계)

3D 소셜 샌드박스 게임 「본사」의 서버와 클라이언트입니다.
현재 단계: 회원가입, 로그인, 멀티플레이 동기화, 채팅 (야외 + 1층 로비).

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `server/index.js` | 웹 서버, 회원가입·로그인 API, 실시간 연결 |
| `server/game.js` | 방(장소) 관리, 이동 검증, 채팅 |
| `server/auth.js` | 비밀번호 해시, 로그인 토큰, 횟수 제한 |
| `server/db.js` | PostgreSQL 저장소 (없으면 연습용 메모리 저장소) |
| `public/` | 브라우저에서 실행되는 게임 화면 |
| `public/world.js` | 서버와 화면이 함께 쓰는 맵·충돌 정보 |
| `schema.sql` | DB 테이블 (서버 시작 시 자동 생성) |

## 무료로 올리는 방법 (Render + Neon)

1. **GitHub**에 가입하고 새 저장소를 만들어 이 폴더의 파일을 모두 올립니다.
2. **Neon**(neon.com)에 가입해 프로젝트를 하나 만들고, 접속 주소(Connection string)를 복사합니다.
   `postgresql://...?sslmode=require` 형태입니다.
3. **Render**(render.com)에 가입해 New → Web Service 를 고르고 위 GitHub 저장소를 연결합니다.
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. Render의 Environment 화면에 환경 변수를 넣습니다.
   - `DATABASE_URL` : 2번에서 복사한 주소
   - `SESSION_SECRET` : 32자 이상의 아무 긴 문자열 (남에게 알려 주지 않습니다)
   - `NODE_ENV` : `production`
5. 배포가 끝나면 Render가 알려 주는 `https://....onrender.com` 주소로 휴대폰에서 접속합니다.

### 무료 요금제의 한계

- Render 무료 서버는 15분 동안 아무도 접속하지 않으면 잠들고, 다시 깨어나는 데 약 1분이 걸립니다.
- Render 무료 서버는 성능이 낮아(CPU 0.1) 동시 접속 100명은 버티기 어렵습니다. 친구 몇 명과 시험하는 용도로 적당합니다.
- 실제 운영 때는 Render의 유료 인스턴스(월 7달러부터)로 바꾸면 코드 수정 없이 그대로 쓸 수 있습니다.
- DB는 Render의 무료 Postgres 대신 Neon을 씁니다. Render 무료 DB는 30일 뒤 만료되기 때문입니다.

## 내 컴퓨터에서 실행

Node.js 20 이상이 필요합니다.

```
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. `DATABASE_URL` 없이 실행하면 연습용 저장소를 쓰며, 서버를 끄면 계정이 사라집니다.

## 2단계에 적용된 보안

- 비밀번호는 bcrypt 해시로만 저장
- 로그인 5번 틀리면 10분 잠금, 가입·API·채팅·이동 패킷 횟수 제한
- 로그인 토큰은 서명되어 있고 24시간 뒤 만료
- 이동은 서버가 속도와 벽 충돌을 다시 검사 (순간이동, 벽 통과 거부)
- 장소 이동은 문 앞에 있을 때만 서버가 허락
- 채팅·닉네임은 서버에서 길이와 문자를 검사하고, 화면에는 텍스트로만 표시 (XSS 방지)
- SQL은 전부 파라미터 바인딩
- 운영 환경에서 HTTPS 강제, 콘텐츠 보안 정책(CSP) 적용
- 가입 200명, 동시 접속 100명 제한, 같은 계정 중복 접속 시 먼저 접속한 쪽 종료

## 기획서와 다르게 정한 것

- 실시간 통신은 Colyseus 대신 가벼운 `ws` 라이브러리로 직접 구현했습니다. 방(장소)별 분리와 서버 권위 구조는 같습니다.
- 내 캐릭터는 화면에서 먼저 움직이고 서버가 검사해 틀리면 되돌립니다. 조작이 끊기지 않게 하기 위해서입니다.
- 로그인 아이디와 게임 닉네임을 따로 받습니다.


## 총관리자 화면 (8단계)

- 주소: `https://<내 주소>/admin` (게임과 분리된 화면. 게임 로그인으로는 들어갈 수 없습니다)
- 들어갈 수 있는 사람: 환경 변수 `SUPERADMIN_USERNAME` 에 적은 아이디 한 명
- 처음 들어갈 때 2단계 인증을 등록합니다. 휴대폰 인증 앱(Google Authenticator 등)에 화면의 키를 "직접 입력"으로 넣고, 앱에 나온 6자리를 입력합니다.
- 그 뒤로는 아이디 + 비밀번호 + 6자리 코드로 들어갑니다. 30분이 지나면 자동으로 로그아웃됩니다.
- 15분 동안 5번 틀리면 15분간 잠깁니다.
- 인증 앱을 잃어버렸을 때: Render 의 Environment 에 `ADMIN_2FA_RESET` = `yes` 를 넣고 저장 → 서버가 다시 켜지면 등록이 지워집니다 → `/admin` 에서 다시 등록 → **`ADMIN_2FA_RESET` 을 반드시 지웁니다** (남겨 두면 서버가 켜질 때마다 초기화됩니다).
- `SESSION_SECRET` 을 바꾸면 저장된 2단계 인증 정보를 읽을 수 없게 되므로, 위 방법으로 다시 등록해야 합니다.


## 9단계: 보안 점검, 부하 시험, 백업

- **백업**: `/admin` → 개요 → "백업 파일 내려받기". 일주일에 한 번쯤 받아 안전한 곳에 보관합니다(암호화된 비밀번호가 들어 있습니다). Neon 무료 요금제는 최근 6시간 안의 시점으로 되돌리는 기능도 있습니다.
- **횟수 제한 조절** (환경 변수, 넣지 않으면 기본값): `SIGNUP_PER_HOUR`(한 IP당 1시간 가입 수, 30), `SIGNUP_PER_HOUR_ALL`(전체 합계, 80), `WS_PER_MIN`(한 IP당 1분 접속 수, 120), `API_PER_MIN`(40). 한 사무실에서 여러 명이 같은 인터넷으로 한꺼번에 가입한다면 `SIGNUP_PER_HOUR` 를 잠시 올리세요.
- **부하 시험** (시험용 서버에서만): `node scripts/loadtest.js <주소> <인원> <초> [서버 프로세스 번호]`. 파일 맨 위에 쓰는 법이 있습니다.
